Quinta Foz do Sabor

BRAND ID

Brand ID for Quinta Foz do Sabor, a viticulture project that produces the best grapes for Port Wine production in the Douro Superior region.

To create the brand ID, we used the usual elements in logos of this nature: seal [brand mark], the name of the project [Quinta Foz do Sabor], the date it was founded [2013] and its location [Douro Superior, Vale do Sábor].

As this is a recent project managed by a young team, we have given this classic composition a contemporary feel through modern fonts and fine lines.
